# Not a tool — a library

SploitAgent captures how the work is actually done — find the bug, prove impact, escalate, pivot, report, and defend — as small, trigger-tagged skills in the standard Agent-Skills format. Drop it in front of any AI agent and the right skill loads itself for the task. No runtime, no lock-in: plain Markdown you can read, grep, copy, and improve.

# Use it with any agent

The skills are plain Markdown, so any agent can use them.

Claude Code

# open it in the repo — CLAUDE.md drives it
git clone https://github.com/NoorQureshi/SploitAgent && cd SploitAgent
claude
# …or load skills everywhere
ln -s "$PWD/skills" ~/.claude/skills/sploitagent

Codex / Gemini / others

# they read AGENTS.md automatically
git clone https://github.com/NoorQureshi/SploitAgent && cd SploitAgent
codex        # or: gemini

Local LLMs (Ollama)

# bake the operating guide into a model
printf 'FROM qwen2.5-coder:14b\nSYSTEM """%s"""' "$(cat AGENTS.md)" > Modelfile
ollama create sploitagent -f Modelfile
ollama run sploitagent

Any other agent

Give it read access to skills/ and AGENTS.md, or paste one SKILL.md for the task.

Full setup for every agent →

Authorized use only. The first skill every engagement loads is tradecraft-scope-roe — SploitAgent acts only inside a confirmed envelope: a signed pentest scope, a bug-bounty program you're in scope for, or systems you own. Never point it at anything else.
